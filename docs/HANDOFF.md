Fix: `curl` the Stack Exchange docs pages and strip the HTML; confirm the Hacker News endpoint by calling it and reading the field names from the algolia/hn-search README.
- 2026-11-22: Stack Exchange returned 0 questions for "GPU cloud rental cost" and the reply showed `quota_remaining` 299. Root cause: long phrases match nothing, and without an app key the quota is about 300 a day, not the 10,000 the docs mention. Fix: 3 short phrases in `queries.py`, and keep requests per run small (12).
- 2026-11-22: `httpx` and `pytest` were not installed, and listing Groq's models with Python's default User-Agent returned 403. Fix: a stdlib `urllib` helper that sets a generic User-Agent and unzips gzip; tests use `unittest`.
- 2026-11-22: a Python script printing a Stack Exchange docs symbol crashed on the Windows console (`UnicodeEncodeError`, cp1252). Fix: run with `PYTHONIOENCODING=utf-8`.
- 2026-11-22: during the model smoke test, `gemini-3.8-flash` timed out after 60 s and OpenRouter's free models returned 429 (upstream rate limit). Not fixed: the fallback chain skips them. Retest before switching to `LLM_MODE=final`.

- 2026-11-22: the first live draft cited one fact eight times (billing, taxes, plans...) although its quote supported none of them. Root cause: the check only proved the quote exists on the page, and the light model stretched one quote across many claims. Fix: the prompt now says one fact supports one claim, and `parse_draft()` rejects a fact cited more than 3 times (the retry sends the reason back). The next live run gave 13 separate facts. Lesson: a validator you can run offline is not proof the output is good; run the real model on a real page.
- 2026-11-22: during the live run the API returned 500 on the last call: Neon closed the database connection ("server closed the connection unexpectedly"). Not our code; the cleanup a second later connected fine. Not fixed. If it repeats, retry the connection once in `get_conn()`.
- 2026-11-22: a guessed provider address (yottasha.com) did not exist, so the download failed with a DNS error. Handled: the API returns 502 saying "paste its text instead". Lesson: take provider URLs from the provider's own site, not from memory.

- 2026-11-22: the Board design's drawer cut off its own top bar when a draft was long. Root cause: in a flex column, a child's minimum height defaults to its content, so the long body pushed the bar out instead of scrolling. Fix: `flex: 1; min-height: 0` on the drawer body. Found only by screenshotting a long draft.
