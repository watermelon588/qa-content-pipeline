Root cause: long phrases match nothing, and without an app key the quota is about 300 a day, not the 10,000 the docs mention. - 2026-11-22: `httpx` and `pytest` were not installed, and listing Groq's models with Python's default User-Agent returned 403. Fix: a stdlib `urllib` helper that sets a generic User-Agent and unzips gzip; tests use `unittest`.
